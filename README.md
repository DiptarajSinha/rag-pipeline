# RAG Pipeline API

This is a production-ready, cloud-persistent RAG (Retrieval-Augmented Generation) pipeline built with **FastAPI**, **Google Gemini**, and **Supabase**.

## Key Features
- **AI-Powered Search**: Uses Gemini's high-performance embeddings.
- **Persistent Storage**: Document metadata and vectors are stored permanently in **Supabase**.
- **Fast & Lean**: Optimized Docker image that runs efficiently on free-tier CPU instances.

## API Documentation
Once the space is running, you can access the interactive Swagger documentation at the `/docs` endpoint.
